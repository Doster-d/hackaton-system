# 🎨 Dashboard Showcase

## 1. Темы и фирменные цвета
- В `hackaton_system/dashboard/app.py` определены две палитры (`THEME_PALETTES`): светлая и тёмная. Цвета повторяют референс (жёлтый RGB 255-210-0, оранжевый 239-107-1, серые оттенки 186-226-242, синие 71-105-149).
- Переключатель темы доступен в сайдбаре (`Настройки отображения → Тёмная тема`) и меняет фон, кнопки, формы, предупреждения и таблицы.

## 2. Ключевые элементы UI
| Элемент | Описание | Где смотреть |
| --- | --- | --- |
| Hero-блок | Gradient background + иконка 🏭, повторяет жёлтые баннеры из макета. | `app.py` (разметка `.hero`) |
| Метрики | Карточки с жёлтыми значками, мягкой тенью и крупными цифрами. | `_render_metric` |
| Графики | Plotly area/bar/heatmap/timeline со списками цветов из палитры. | `headcount_fig`, `duration_fig`, `heatmap_fig`, `timeline_fig` |
| Alerts | Кастомные стили для `st.info/warning/success` под фирменные цвета. | CSS блок `div[data-testid="stAlert"]` |
| Таблица эпизодов | pandas Styler + фон/бордеры по теме. | секция «Таблица эпизодов» |
| Промпт-редактор | Expander с текущими промптами + textarea для редактирования VideoLLaMA3. | конец файла `app.py` |

## 3. Сценарий демонстрации
1. Запустить `streamlit run hackaton_system/dashboard/app.py` (см. README).
2. Показать загрузку видео, запуск пайплайна и появление превью.
3. Переключить тему и пролистать:
   - Headcount area chart;
   - Bar chart времени по активностям;
   - Heatmap «роль × активность»;
   - Таймлайн движения и таблицу эпизодов с фильтрами.
4. Зайти в раздел «Управление промптами», выбрать класс YOLO и обновить подсказки для VideoLLaMA3.

## 4. Советы для скриншотов
- Используйте разрешение 1920×1080 и масштаб 100 %, чтобы градиенты выглядели чётко.
- На светлой теме делайте акцент на экономический эффект (метрики + таблица), на тёмной — графики и видео.
- Для GIF можно записать короткую сессию переключения темы и фильтрации таблицы (OBS + ffmpeg).
